# redrock_welcome

红岩网校招新群欢迎插件

## 简介

- **作者**: Redrock
- **版本**: 1.0.0

## 功能

监听群成员增加事件（`group_increase`），当有新成员加入招新群时，自动发送欢迎消息并附带招新海报。

## 命令

本插件无需手动指令，新成员入群时自动触发。

| 事件 | 说明 |
| ---- | ---- |
| 群成员增加 | 自动 @ 新成员并发送欢迎语与海报 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

- `enabled`：是否启用本插件
- `welcome_text`：新成员入群时发送的欢迎文本
- `welcome_image`：欢迎消息附带的海报图片路径
