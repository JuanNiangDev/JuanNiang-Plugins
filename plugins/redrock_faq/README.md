# redrock_faq

红岩网校 FAQ 查询插件（命令式）

## 简介

- **作者**: Redrock
- **版本**: 1.1.0

使用 `/redrock <关键词>` 命令查询红岩网校相关信息：网校介绍、部门介绍、如何加入、成果、位置、新生导航等，另附命令式触发的卷娘闲聊彩蛋。

## 功能

- `/redrock`（无参数）：显示查询清单
- `/redrock <关键词>`：查询对应信息（部门、加入、位置、学习、招新、成果、导航等）
- 群聊与私聊均可使用；群聊回复会 @ 提问者

## 命令

| 命令 | 说明 |
| ---- | ---- |
| `/redrock` | 显示查询清单 |
| `/redrock 网校` | 红岩网校介绍 |
| `/redrock 部门` | 七个部门总览 |
| `/redrock 前端` 等 | 具体部门介绍（产品/视觉/前端/后端/移动/运维/ai/安卓/ios） |
| `/redrock 加入` | 如何加入红岩网校 |
| `/redrock 位置` | 网校位置 |
| `/redrock 学习` | 能学到什么 |
| `/redrock 招新` | 招新活动 |
| `/redrock 成果` | 网校成果 |
| `/redrock 新生导航` | 新生导航 |
| `/redrock 趣味功能` | 游戏/功能清单 |
| `/redrock 3g` | 重邮 3G 科普彩蛋 |
| `/redrock 在吗` / `/redrock emo` 等 | 闲聊彩蛋 |

> 参数支持别名与包含匹配（如 `/redrock 前端研发部` 等同 `/redrock 前端`）；查不到时提示查看清单。

## 配置

本插件无配置项（纯命令式查询）。
