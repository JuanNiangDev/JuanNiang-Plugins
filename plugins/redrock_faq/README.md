# redrock_faq

红岩网校招新群关键词问答插件

## 简介

- **作者**: Redrock
- **版本**: 1.0.0

红岩网校招新群的关键词问答机器人。@卷娘 或私聊触发，可回答部门介绍、如何加入、成果、位置、新生导航等常见问题，并附带卷娘的日常闲聊语料库。

## 功能

- 群聊中 @卷娘 触发，私聊直接发送消息触发
- 部门介绍（前端、后端、移动、运维、AI 等七个部门）
- 招新、加入方式、成果、位置、新生导航等常见问题
- 卷娘日常语料库（"在吗""内卷""emo""吃饭"等闲聊）
- 私聊数字菜单引导（1-5）
- 重邮特色彩蛋（"3G"科普等）

## 命令

本插件无 / 命令，通过 @ 或关键词直接触发。

| 触发方式 | 说明 |
| ---- | ---- |
| @卷娘 + 关键词 | 群聊中触发关键词问答 |
| 私聊发送关键词 | 私聊触发闲聊语料库 |
| 私聊发送 1-5 | 数字菜单引导 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置。

| 配置项 | 类型 | 说明 | 默认值 |
| ---- | ---- | ---- | ---- |
| bot_name | string | 卷娘称呼（用于 @ 匹配） | 卷娘 |
| enable_chat_rules | bool | 是否启用日常语料库回复 | true |
