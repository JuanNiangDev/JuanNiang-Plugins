# redrock_special

卷娘彩蛋关键词插件

## 简介

- **作者**: Redrock
- **版本**: 1.0.0

## 功能

当群聊中提及或 @ 卷娘并包含特定关键词（如「年龄」「身高」「体重」「喜欢什么颜色」「周末干嘛」等）时，
插件会触发彩蛋回复，部分回答还会随机附带一组图片。

## 命令

本插件无需手动指令，直接发送关键词即可触发彩蛋回复。

| 玩法 | 说明 |
| ---- | ---- |
| 提及关键词 | 在群聊中 @ 卷娘或输入「卷娘」并包含彩蛋关键词 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

- `enabled`：是否启用本插件
- `bot_name`：机器人称呼，用于识别群内触发彩蛋时的提及
