# redrock_welcome

红岩网校招新群欢迎插件

## 简介

- **作者**: Redrock
- **版本**: 1.1.0

## 功能

监听群成员增加事件（`group_increase`），新成员先进入缓冲区攒批，统一发送欢迎消息并附带招新海报：

- 攒满 `batch_size` 人（默认 15）→ 立即发送
- 首人入队起算 `flush_seconds` 秒（默认 3）内未攒满 → 到点直接发送现有缓冲
- 发送后计时器清零，下一名新成员重新开启一轮

欢迎消息为一条群消息：对所有本批新成员逐个 @，后接欢迎语文本与海报图片。

## 命令

本插件无需手动指令，新成员入群时自动触发。

| 事件 | 说明 |
| ---- | ---- |
| 群成员增加 | 进入缓冲区攒批，攒满或窗口到点后一条消息 @ 全部并发送欢迎语与海报 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

- `enabled`：是否启用本插件
- `welcome_text`：欢迎文本（@ 段之后追加）
- `welcome_image`：欢迎消息附带的海报图片路径
- `batch_size`：攒满多少名新成员后立即统一发送（数字，以文本形式填写）
- `flush_seconds`：发送窗口秒数，首人入队起算，到点统一发送（数字，以文本形式填写）
