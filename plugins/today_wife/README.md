# today_wife 今日老婆

群聊趣味插件：随机抽老婆、强娶、离婚、全员老婆、老婆关系网拓扑图，以及需要双方同意的**固定永恒 CP**。

复刻自 [astrbot_plugin_today_wife](https://github.com/xiaolongxia521/astrbot_plugin_today_wife)，按 JuanNiang-Neo 架构重写（Lua + PostgreSQL + Redis + T2I）。

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/今日老婆` | `/查老婆` `/我的老婆` | 查看当前全部群老婆（💍 标记固定永恒老婆） |
| `/随机老婆` | `/娶老婆` `/抽老婆` | 从活跃群友中随机抽取一位；配置了固定配对时优先返回固定老婆 |
| `/强娶 @某人` | — | 强制绑定指定群友（支持 @ 或直接填 QQ 号） |
| `/离婚 @某人` | `/休妻` | 解除普通老婆关系（固定永恒老婆受保护） |
| `/所有人都是我老婆` | `/全都要` | 把群内**活跃**群友一次性全部娶为老婆 |
| `/强娶全体成员` | `/全员老婆` | 把群内**全体成员**（含不活跃）一次性全部娶为老婆 |
| `/全部离婚` | `/净身出户` | 一次性解除全部普通老婆关系（固定配对保留） |
| `/老婆关系网` | `/绿帽图` `/本群关系` | 用 T2I 渲染本群当日老婆关系拓扑图 |
| `/固定老婆 @某人` | — | 发起固定永恒 CP 邀请，需对方同意 |
| `/同意固定老婆` | — | 同意绑定（被邀请者） |
| `/拒绝固定老婆` | — | 婉拒绑定（被邀请者） |
| `/解除固定老婆 @某人` | — | 发起解绑；**群管理员/群主可直接解绑**，普通成员需对方同意 |
| `/同意解除固定老婆` | — | 同意解绑（被邀请者） |

> 命令前缀由实例配置决定，上表以 `/` 为例。

## 固定永恒 CP（核心特性）

- **双向同意**：A 发 `/固定老婆 @B` → B 发 `/同意固定老婆` 才生效（邀请 5 分钟内有效）。
- **双向绑定**：绑定成功后 A↔B 互为固定老婆，每日重置不会分离。
- **互斥保护**：任一方已有固定老婆时，新的邀请会被拒绝。
- **解绑保护**：普通 `/离婚` 对固定配对无效；解绑需双方同意，群管理员可单方解绑。
- **后台预置**：也可在 WebUI 的「分群固定配对配置」里直接写入 JSON，插件启动后自动落库。
  ```json
  {"641370366": {"111111111": "222222222"}}
  ```
  含义：群 641370366 中，111111111 的固定老婆是 222222222（单向；双方都写则互为固定）。
  后台删除需配合 `/解除固定老婆`（群管可单方面解除命令创建的配对）。

## 关系网拓扑图

- 环形布局，节点为 QQ 头像 + 群昵称。
- 单向钟情：蓝色箭头线；双向奔赴：粉色弧线 + 💗；固定配对：红色线 + 💍 + 加粗粉边。
- 画布宽度固定 1200px，**高度随节点数自适应**（`full_page` 整页截图），不会出现大片空白。
- 单群每日生成次数由 `max_relationship_graph_count` 限制（保护渲染性能）。

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_groups` | `[]` | 启用群列表，**留空表示所有群生效**；填 `*` 亦表示全部 |
| `group_cooldown_seconds` | `5` | 同群指令冷却（秒），0 为不限制 |
| `user_cooldown_seconds` | `10` | 同用户指令冷却（秒），0 为不限制 |
| `reset_hour` | `4` | 每日数据与次数重置的小时点（0-23） |
| `active_days` | `3` | 活跃群友判定天数（随机老婆的候选池来源） |
| `fixed_pairings` | `{}` | 分群固定配对 JSON，见上 |
| `max_random_count` | `5` | 每日随机老婆次数上限（0 为不限） |
| `max_marry_count` | `3` | 每日强娶次数上限 |
| `max_divorce_count` | `2` | 每日离婚次数上限 |
| `max_all_marry_count` | `1` | 每日「所有人都是我老婆」次数上限 |
| `max_force_all_marry_count` | `1` | 每日「强娶全体成员」次数上限 |
| `max_all_divorce_count` | `1` | 每日「全部离婚」次数上限 |
| `max_relationship_graph_count` | `3` | 每群每日关系网生成次数上限 |
| `enable_cat_tone` | `true` | 回复结尾是否带「喵~」 |
| `not_in_group_text` | `你绑定的永恒老婆今天不在这个群里哦~` | 固定老婆不在群时的提示语 |

## 数据与实现

- **PostgreSQL 三张表**（自动建表、自动清理）
  - `pluggin_today_wife_pairings`：配对（`is_fixed` 区分固定/当日，`pair_date` 为逻辑日期）
  - `pluggin_today_wife_counts`：每日次数（`group_id+user_id+stat_date+action` 唯一）
  - `pluggin_today_wife_active`：活跃群友（`last_seen` 为 Unix 秒，按 `active_days` 过滤）
- **Redis**
  - 冷却键（`cd:g:*` / `cd:u:*`，TTL 即冷却时长）
  - 固定配对邀请态（`fixreq:*` / `fixunbind:*`，TTL 5 分钟）
  - 群成员昵称映射缓存（10 分钟，避免每条指令都拉成员列表）
- **每日重置为惰性触发**：任何指令执行前按 `reset_hour` 计算逻辑日期并清理非当日数据，不依赖定时器是否准点。
- 后台另有一个 6 小时周期的清理任务，回收过期活跃记录、7 天前的配对与次数。
