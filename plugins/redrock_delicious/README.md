# redrock_delicious 干饭语录

CronJob 触发后，随机向指定群发送一条吃饭语录。语录统一开头
**"该吃饭了，卷娘到 xxx 吃了 xxx"**，结尾评价各不重复，内容为红岩er 亲测的中心食堂一楼/二楼与校外觅食推荐。

## 语录库

内置 20 条，覆盖：

- **中心食堂一楼**：掉渣饼、煎饼果子、岩烧乳酪面包、咖啡面包、番茄鸡蛋滑蛋饭、瑞幸咖啡、宜宾素燃面、轻食、麦当劳、藤椒抄手
- **中心食堂二楼**：兰州拉面的番茄鸡蛋盖浇面、贵州蘸水菜、山城小火锅
- **校外**：兰馨面庄、六婶老火锅、中原面馆、肠粉、彩蝶轩、福建千里馄饨王

## 使用方法

1. 面板安装并启用本插件；
2. 定时消息（积木式编排）或 CronJob 中新建定时任务，插件选 `redrock_delicious`；
3. Payload 填写目标群号：

```json
{ "groups": [123456, 789012] }
```

4. cron 示例：`0 30 11 * * *`（每天 11:30 开饭提醒）。

## 配置项

| key | 类型 | 说明 |
| --- | --- | --- |
| `extra_quotes` | list | 追加到随机语录库末尾的自定义语录，留空只用内置语录 |
