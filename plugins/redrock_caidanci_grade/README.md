# redrock_caidanci_grade

红岩网校分级猜单词小游戏（Wordle）

## 简介

- **作者**: Redrock
- **版本**: 2.2.1

基于 Wordle 规则的猜单词小游戏，支持高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE 七档难度（默认四级）。可指定难度与单词长度开局，猜测反馈由 T2I 渲染为棋盘图片（本地 PoetsenOne 字体，无远程字体依赖），游戏状态按群隔离。猜对或主动结束时展示单词中文释义。

## 功能

- 七档难度词库：高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE，默认四级
- `/猜单词 <难度> <长度>` 与 `/猜单词 <长度> <难度>` 参数顺序任意
- 未指定长度时默认 4–6 字母随机；显式长度支持 4–10（可配置）
- 开局发送空白棋盘图片（T2I 可用时），不再用下划线占位
- 棋盘按单词长度预设渲染尺寸（viewport + full_page=false），避免图片大面积空白
- 当前轮次（最近一次输入的那一行）柔和发光标识；已猜格与空格一致的灰色边框
- 最多 6 次猜测机会（可配置）
- 猜词校验：不在全部词库并集中的词会提示「你确定 <单词> 是一个单词吗」
- 猜对与 `/结束` 时展示目标单词的中文释义（次数用尽不展示）
- `/提示` 在猜错的位置揭示正确字母（棋盘上该格为 #00BFFF）
- 棋盘图片按棋盘状态缓存；T2I 不可用时自动降级为 emoji 文本反馈
- 提供 `/结束` 结束当前游戏并展示棋盘
- 支持「没意思」「有啥好玩」等关键词引导开局

## 命令

| 命令 | 说明 |
| ---- | ---- |
| /猜单词 | 开始一局猜单词游戏（默认四级，长度 4-6 随机） |
| /猜单词 <难度> | 指定难度开局（高考/四级/六级/考研/雅思/托福/GRE） |
| /猜单词 <长度> | 指定单词长度开局（4-10，默认四级） |
| /猜单词 <难度> <长度> | 同时指定难度与长度（顺序任意） |
| /猜单词 帮助 | 查看帮助菜单 |
| /猜 <单词> | 提交猜测 |
| /提示 | 揭示一个猜错位置的正确字母 |
| /结束 | 结束当前游戏并展示答案 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置。

| 配置项 | 类型 | 说明 | 默认值 |
| ---- | ---- | ---- | ---- |
| default_difficulty | string | 默认难度 | 四级 |
| default_length_min | string | 随机长度下限 | 4 |
| default_length_max | string | 随机长度上限 | 6 |
| max_length | string | 允许的最大长度 | 10 |
| max_attempts | string | 最大猜测次数 | 6 |
| enable_trigger | bool | 是否启用引导触发 | true |

## 卷娘预设语句

以下为卷娘在本插件中会发送的全部预设文案。动态内容用占位符标注：`<难度>`（高考/四级/六级/考研/雅思/托福/GRE）、`<长度>`（单词字母数）、`<单词>`（目标/猜测单词）、`<次数>`（剩余或已用次数）、`<位置>`（字母位置序号，从 1 开始）、`<字母>`（大写字母）。

### 开始游戏（/猜单词）

- `🎮 猜单词游戏开始！`
- `难度：<难度> ｜ 单词长度：<长度> 个字母 ｜ 最多 <次数> 次机会`
- 空白棋盘图片（T2I 可用时；降级为 `<长度> 个占位符：_ _ _ _ ...`，如 `_ _ _ _ _`）
- `发送 /提示 获取帮助 ｜ /结束 退出游戏`

### 参数错误（/猜单词）

- `猜单词游戏仅在群聊中可用哦～`（私聊触发时）
- `本群已有进行中的猜单词游戏啦！\n发送 /结束 可以结束当前游戏。`
- `无法识别的参数：<参数>`
- `长度参数重复指定了` / `难度参数重复指定了`
- `单词长度必须是整数`
- `单词长度只支持 4～10，未指定时默认 4-6 随机`
- `该难度词库中暂时没有 <长度> 字母的单词，换个长度试试～`

### 猜测反馈（/猜）

猜错时从以下鼓励语中**随机**挑选一句，连同棋盘图片一起发送：

- 猜对 3 个及以上字母：`超对！就这样继续～💪` / `很棒！大部分都对了！` / `卷娘觉得你离答案越来越近了！` / `厉害呀，方向完全正确！`
- 猜对 1–2 个字母：`有好几个字母对了！加油～` / `开头不错，再想想后面的～` / `方向是对的，继续尝试！` / `很不错，再调整一下就好！`
- 剩余 1 次：`最后一次机会啦！卷娘相信你一定能猜出来✨`
- 剩余 2 次：`还有<次数>次机会，用 /提示 获取帮助哦～`
- 其余情况随机：`别急，慢慢来～` / `加油，卷娘觉得你可以的！` / `再试一个试试，说不定就对啦～` / `猜单词就像 debug，多试几次总能找到问题所在😜`
- 剩余次数 ≤3 时附：`（剩余 <次数> 次，发送 /提示 获取帮助）`

猜测输入校验：

- `请输入要猜的单词，例如：/猜 apple`
- `单词长度不对哦～当前单词有 <长度> 个字母`
- `请输入纯英文字母的单词～`
- `你确定 <单词> 是一个单词吗`（不在全部词库并集中时）
- `这个单词已经猜过啦～换一个试试吧！`

### 提示（/提示）

- `💡 提示：第 <位置> 位是 <字母>`（如 `💡 提示：第 3 位是 A`）
- `提示已经给完啦！卷娘相信大家能猜出来的💪`

### 猜对（胜利）

随机挑选一句，连同最终棋盘图片与释义发送：

- `🎉 恭喜！你猜对了！答案就是 <单词>！`
- `✨ 太厉害了！<单词> 就是这个单词！`
- `🏆 完美！<单词>，猜词大师就是你！`
- `👏 不错哦～<次数> 次就猜出了 <单词>！`

### 次数用尽（失败）

随机挑选一句，连同最终棋盘图片发送（不展示释义）：

- `😢 次数用完啦～答案是 <单词>，下次一定能猜出来的！`
- `💨 揭晓答案：<单词>！没关系，再来一局？`
- `🤗 差一点就对啦～答案是 <单词>，要不要再玩一次？`

### 结束（/结束）

- `游戏已结束！答案是：<单词>\n📖 <释义>\n\n发送 /猜单词 可以再来一局～`

> 释义以 `📖 <释义>` 形式仅追加在猜对（胜利）与 `/结束` 消息末尾；次数用尽等其他情况不展示。词库无释义时省略该行。
- `本群还没有进行中的游戏哦～发送 /猜单词 来一局吧！`（无进行中游戏时，/猜、/提示、/结束 通用）

### 引导触发（on_message）

检测到「没意思 / 没劲 / 有啥好玩 / 有什么好玩 / 好玩的 / 玩什么」关键词且本群无进行中游戏时：

- `来玩猜单词呀！@卷娘 /猜单词 就能开局～\n看看你能用几次猜出正确答案 🤔`

### 帮助菜单（/猜单词 帮助）

- `- /猜 — 提交猜单词的猜测`
- `- /猜单词 — 玩一局猜单词游戏（Wordle）`
- `- /猜单词 <难度> — 指定难度高考/四级/六级/考研/雅思/托福/GRE`
- `- /猜单词 <长度> — 指定单词长度`

> 说明：T2I 不可用时，`/猜`、`/提示`、`/结束` 的回复会降级为纯文本，并在末尾追加 emoji 版猜测记录（形如 `第1次：🟩⬜⬜⬜⬜  apple`）。

## 词库

词库为插件目录下的单个 `words.csv`（由高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE 七档词库合并生成，已去除音标列），列结构：

| 列 | 说明 |
| ---- | ---- |
| word | 单词（小写纯字母） |
| translation | 中文释义（可含逗号，CSV 引号包裹；`\n` 为换行） |
| tag | 难度标识（gaokao/cet4/cet6/kaoyan/ielts/toefl/gre） |

启动时一次性加载进内存哈希索引（随机选词 / 词典校验 / 释义查询均为 O(1)，无外部存储依赖）：

| 索引 | 用途 |
| ---- | ---- |
| words_by_len[难度][长度] | 按难度与字母数随机选词 |
| union_words | 猜词词典校验（全部词库并集） |
| word_trans | 单词中文释义（重复跨难度的单词按首个释义去重） |

加载时自动过滤非纯字母条目（连字符、带空格短语、缩写等）。当前共 37151 条词条 / 14837 个唯一单词。
