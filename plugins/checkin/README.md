# 签到插件 (checkin)

签到插件，提供 `/qd` 签到和 `/rank` 排行榜功能。

## 简介

- **作者**: JuanNiang-Neo
- **版本**: 1.0.5

## 功能

- `/qd` 每日签到，随机获得 1-10 积分
- `/rank` 查看签到积分排行榜（前十名）
- 签到成功后附带每日一句金句（可通过配置开关）
- 使用数据库持久化签到记录

## 命令

| 命令  | 说明                         |
| ----- | ---------------------------- |
| /qd   | 每日签到，随机获得 1-10 积分 |
| /rank | 查看签到积分排行榜（前十名） |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

| 配置键             | 类型 | 说明                                            |
| ------------------ | ---- | ----------------------------------------------- |
| score_range        | string | 每次签到随机获得的积分范围，默认 `1-10`          |
| enable_quote       | bool   | 是否附带每日金句，默认 `true`                    |
| rank_limit         | string | /rank 排行榜显示人数，默认 `10`                  |

## 语录库

签到成功后的每日金句取自插件目录内的 `quotes.txt`，该文件是语录的**权威来源**：

- 一行一句，`#` 开头的行视为注释（分类标记），空行会被跳过；
- 当前收录 **80** 条，按日常 / 坚持 / 心态 / 幽默 / 温柔 / 四季与自然分组；
- 增删句子只需编辑 `quotes.txt`，保存后在 Web 面板 reload 插件即可生效；
- 插件加载时会把整份语录写入 Redis（key `quotes`，实际 Redis key 为
  `juan:pluggin:checkin:quotes`）作为缓存，每次加载整体覆盖，重复加载结果一致；
- Redis 不可用时自动回退到插件内存副本，签到功能不受影响；
- `quotes.txt` 缺失或内容为空时，使用内置的 5 条兜底句。
