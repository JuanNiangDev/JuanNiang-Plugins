# welcome

入群欢迎插件

## 简介

- **作者**: JuanNiang
- **版本**: 1.0.0

## 功能

监听群成员增加事件（`group_increase`），当新成员入群时自动发送欢迎消息。支持两种入群方式：

- 管理员同意入群（`approve`）
- 群友邀请入群（`invite`，会特别提及邀请人）

## 命令

本插件无需手动指令，新成员入群时自动触发。

| 事件 | 说明 |
| ---- | ---- |
| 群成员增加 | 自动 @ 新成员并发送欢迎语 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

- `enabled`：是否启用本插件
