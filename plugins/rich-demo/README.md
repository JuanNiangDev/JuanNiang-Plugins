# 富文本图片示例插件 (rich-demo)

演示使用消息段发送带图片的富文本消息，注册 `/rich` 命令。

## 简介

- **作者**: JuanNiang
- **版本**: 1.0.0

## 功能

- 注册 `/rich` 命令，发送文本 + 图片 + 表情的富文本消息
- 图片从插件目录读取（`test.png`），自动转 base64
- 支持群聊与私聊场景

## 命令

| 命令   | 说明                             |
| ------ | -------------------------------- |
| /rich  | 发送带图片的富文本示例消息       |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

| 配置键     | 类型   | 说明                                   |
| ---------- | ------ | -------------------------------------- |
| image_file | string | 图片文件名，默认 `test.png`            |
| text_before| string | 图片之前的说明文本                     |
| show_face  | bool   | 是否附加 CQ 表情，默认 `true`          |
