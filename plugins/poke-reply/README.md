# 戳一戳回复插件 (poke-reply)

监听戳一戳 (poke) 事件，自动回复消息。

## 简介

- **作者**: JuanNiang
- **版本**: 1.1.0

## 功能

- 监听 `on_notice` 中的 `notify` / `poke` 事件
- **只响应戳向机器人自己的戳一戳**（比对事件 `target_id` 与机器人 QQ），群成员互戳不误回
- 被戳时随机挑选一条回复语并发送到群里
- 默认 @ 发起戳一戳的人
- 支持自定义回复语列表、开关 @、启停功能

## 命令

本插件无需命令，通过戳一戳事件自动触发。

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

| 配置键            | 类型   | 说明                                         |
| ----------------- | ------ | -------------------------------------------- |
| replies           | list   | 被戳时随机挑选的回复语列表，留空使用内置默认 |
| mention_sender    | bool   | 回复时是否 @ 发起者，默认 `true`             |
| enable_poke_reply | bool   | 是否启用戳一戳回复，默认 `true`              |
| bot_qq            | string | 机器人QQ号（仅戳向此QQ才回复）；留空自动获取 |
