# redrock_caidanci

红岩网校猜单词小游戏（Wordle）

## 简介

- **作者**: Redrock
- **版本**: 1.0.0

基于 Wordle 规则的猜单词小游戏，单词库围绕红岩网校、技术、校园等主题建设。游戏状态按群隔离，使用缓存存储，支持提示、结束、引导触发等功能。

## 功能

- 按群隔离游戏状态，互不干扰
- 支持 4 / 5 / 6 字母三种长度的单词
- 最多 6 次猜测机会（可配置）
- 提供 `/提示` 获取逐步提示（分类、首字母、尾字母、线索）
- 提供 `/结束` 结束当前游戏并展示猜测记录
- 支持"没意思""有啥好玩"等关键词引导开局
- 使用 🟩🟨⬜ 反馈猜测结果

## 命令

| 命令 | 说明 |
| ---- | ---- |
| /猜单词 [-l 长度] | 开始一局猜单词游戏，可指定 4/5/6 长度 |
| /提示 | 获取当前游戏的提示 |
| /结束 | 结束当前游戏并展示答案与记录 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置。

| 配置项 | 类型 | 说明 | 默认值 |
| ---- | ---- | ---- | ---- |
| default_length | string | 默认单词长度（4/5/6） | 5 |
| max_attempts | string | 最大猜测次数 | 6 |
| enable_trigger | bool | 是否启用引导触发 | true |
