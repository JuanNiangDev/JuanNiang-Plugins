# redrock_poke

卷娘戳一戳回复插件

## 简介

- **作者**: Redrock
- **版本**: 1.0.1

当群成员戳一戳**卷娘**时，以卷娘的人设（18 岁狮子座女生，活泼可爱俏皮）结合红岩网校信息进行多样化的俏皮回复。

> 只会响应戳向机器人自己的戳一戳（通过事件中的 `target_id` 与机器人 QQ 比对），
> 群成员之间互戳不会触发回复。

## 功能

- 戳一戳事件自动回复
- 多样化俏皮回复（傲娇、招新引导、游戏引导、性格相关）
- 避免连续两次回复相同内容
- 群聊中 @ 发起戳的人后再回复
- **精准识别**：只回复戳向机器人自己的戳一戳（比对 `target_id`），互戳不误回

## 命令

本插件无聊天命令，由戳一戳（poke）事件触发。

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置。

| 配置项 | 类型 | 说明 | 默认值 |
| ---- | ---- | ---- | ---- |
| enabled | bool | 是否启用戳一戳回复 | true |
| bot_qq | string | 机器人QQ号（仅戳向此QQ才回复）；留空自动获取 | "" |
| poke_replies | list | 戳一戳回复语（留空用内置默认） | [] |

机器人 QQ 的确定顺序：配置 `bot_qq` > 自动调用 `onebot11.get_login_info()`。
留空配置时一般无需手动填写；若自动获取失败（如适配器未连接），插件会暂时停用戳一戳回复并在日志中告警。
