# redrock_quiz

红岩知识快问快答小游戏

## 简介

- **作者**: Redrock
- **版本**: 1.0.0

## 功能

一个关于红岩网校历史、部门与产品的小游戏。发送 `/来一局` 或 `/快问快答` 开始答题，
系统会从内置题库中随机抽取题目，通过 `/答 <答案>` 提交答案，答对得分、答错会累计次数，
答错超过上限或全部答完后结束本局，并给出评价与得分。

## 命令

| 命令 | 说明 |
| ---- | ---- |
| /来一局 | 开始红岩知识快问快答 |
| /快问快答 | 开始红岩知识快问快答（同 /来一局） |
| /答 <答案> | 提交当前题的答案 |
| /结束快答 | 提前结束当前快问快答 |

## 配置

在 Web 管理面板「Plugin 管理」的插件详情「配置」页可调整本插件的配置：

- `enabled`：是否启用本插件
- `max_wrong`：每局最多答错次数
- `questions_per_game`：每局抽取的题数
